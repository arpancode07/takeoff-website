# Takeoff website

Static site — no build step.

## Deploy on GitHub Pages
1. Upload `index.html` and the `assets/` folder to the root of `arpancode07/takeoff-website` (branch `main`).
2. Repo → Settings → Pages → Source: "Deploy from a branch" → `main` / `/ (root)` → Save.
3. Site goes live at https://arpancode07.github.io/takeoff-website/ in ~1 minute.
